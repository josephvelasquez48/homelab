# DNS (CoreDNS)

Runs on the Raspberry Pi, `network_mode: host` so it binds port 53 directly.

- `coredns/Corefile` - two zones: `joseph:53` serves internal hostnames from
  `joseph.hosts`; `.:53` blocks ad/tracking domains via `blocklist.hosts`
  (fallthrough to real upstream resolution otherwise).
- `coredns/blocklist.hosts` - generated by `scripts/update-blocklist.sh`
  from [StevenBlack/hosts](https://github.com/StevenBlack/hosts). Not
  committed (gitignored); run the script once after cloning to create it.
- `systemd/*` - installs a weekly timer to keep the blocklist fresh.
  CoreDNS's `hosts` plugin watches the file and reloads automatically, no
  restart needed. Paths in the `.service` unit are hardcoded to
  `/home/joe/apps/homelab/...` for now (this gets parameterized properly
  once Ansible is introduced).

## Deploy (Pi, manual for now)

```bash
cd ~/apps/homelab/docker/dns
./scripts/update-blocklist.sh
docker compose up -d
sudo cp systemd/coredns-blocklist-update.* /etc/systemd/system/
sudo systemctl enable --now coredns-blocklist-update.timer
```

## Verify

```bash
dig @192.168.1.253 api.joseph +short          # -> 192.168.1.131
dig @192.168.1.253 example.com +short         # -> real answer, forwarded upstream
dig @192.168.1.253 doubleclick.net +short     # -> 0.0.0.0, blocked
```
